# Changelog

All notable changes to this module are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) as Cargo reads it.

## [0.2.76] - 2026-10-01

### Changed

- First release published to crates.io. The framework and sibling modules are taken from
  crates.io by semver requirement instead of by git tag.
- The package description is shortened to fit crates.io's 1000-character limit.

### Note

- `v0.2.75` exists as a git tag but was never published: crates.io refused it because the
  package description was longer than 1000 characters. Depend on 0.2.76 or later.
